# Seelenbann

Ein düsteres 2D-Rollenspiel: Bezwinge die Kreaturen des Friedhofs, banne ihre Seelen und lass sie für dich kämpfen.

**Spielen:** im Browser über GitHub Pages (Link unter *Settings → Pages*). Auf dem Handy quer halten,
über „Zum Startbildschirm hinzufügen“ startet es wie eine App.

**Steuerung:** Pfeiltasten/WASD + Leertaste (Tastatur) oder Steuerkreuz + A-Taste (Touch).

Stand: Meilenstein 2 – Rundenkämpfe gegen wilde Kreaturen im Grabmoos des Friedhofs. Bannen folgt.
